# Roles and Responsibilities

| Role | Responsibilities |
|---|---|
| Security Engineering Lead | Owns program direction, prioritization, executive reporting, and governance cadence |
| Detection Engineer | Develops, tests, and maintains detection logic and coverage metrics |
| Vulnerability Manager | Prioritizes vulnerability findings and tracks remediation SLAs |
| Cloud Security Owner | Reviews cloud controls, remediation plans, and exceptions |
| Application Owner | Remediates application and pipeline findings |
| System Owner | Remediates infrastructure and endpoint findings |
| Security Architect | Reviews threat models, design risks, and compensating controls |
| Incident Response Analyst | Triage alerts, escalates incidents, and documents outcomes |
| Executive Sponsor | Approves risk appetite, major exceptions, and roadmap priorities |

## Accountability Model

Security owns standards, risk visibility, and validation. Engineering and system owners own remediation. Leadership owns risk acceptance when remediation is delayed or declined.
