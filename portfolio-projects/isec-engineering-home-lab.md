# ISec Engineering Home Lab

## Source Repository

https://github.com/carrollj8471-ux/ISec-Engineering-Home-Lab

## Program Area

Security Operations and Monitoring

## Project Purpose

This project demonstrates hands-on security operations concepts through lab-based telemetry, monitoring, alerting, and endpoint visibility.

## Technical Work Demonstrated

- Security lab architecture
- Endpoint and network telemetry
- Alert review
- SIEM-style analysis
- Operational security documentation

## Management Integration

- Security operations review
- Alert triage metrics
- Monitoring coverage tracking
- Incident response readiness
- Executive visibility into detection posture

## Key Metrics

- Alerts reviewed
- High-priority alerts escalated
- Mean time to triage
- Monitored assets
- Telemetry gaps

## Security Leadership Value

This project shows the ability to connect hands-on monitoring work to operational reporting and security program visibility.
