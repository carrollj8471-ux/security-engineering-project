# Security Baseline Compliance Scanner

## Source Repository

https://github.com/carrollj8471-ux/security-baseline-compliance-scanner

## Program Area

Compliance Engineering

## Project Purpose

This project demonstrates how baseline security controls can be checked, reported, and tracked for remediation.

## Technical Work Demonstrated

- Baseline control scanning
- Pass/fail control reporting
- Failed-control analysis
- Remediation recommendation
- Compliance evidence generation

## Management Integration

- Compliance KPI reporting
- Remediation backlog
- Control owner accountability
- Monthly scorecard
- Risk review for failed controls

## Key Metrics

- Controls passing
- Failed controls by severity
- Repeat failures
- Remediation SLA performance
- Exceptions open

## Security Leadership Value

This project shows the ability to translate control checks into governance, accountability, and measurable compliance posture.
