# DevSecOps Security Pipeline

## Source Repository

https://github.com/carrollj8471-ux/devsecops-security-pipeline

## Program Area

DevSecOps Security

## Project Purpose

This project demonstrates how security checks can be embedded into CI/CD workflows to identify issues before release.

## Technical Work Demonstrated

- CI/CD security scanning
- Policy gates
- Dependency or code security checks
- Pipeline failure handling
- Developer remediation workflow

## Management Integration

- Secure release governance
- Remediation SLA tracking
- Exception review
- Security gate adoption metrics
- Application owner accountability

## Key Metrics

- Repositories with security gates
- Pipeline findings by severity
- Failed builds due to security policy
- Remediation time
- Approved exceptions

## Security Leadership Value

This project shows the ability to connect engineering delivery pipelines to security governance without losing accountability for risk decisions.
