# Cloud Security Posture

## Source Repository

https://github.com/carrollj8471-ux/Cloud-security-posture

## Program Area

Cloud Security Governance

## Project Purpose

This project demonstrates cloud security control assessment, failed-control review, remediation planning, and posture reporting.

## Technical Work Demonstrated

- AWS control assessment
- Cloud misconfiguration review
- Security findings analysis
- Remediation recommendations
- Control evidence documentation

## Management Integration

- Enterprise risk register
- Remediation backlog
- Cloud control governance
- Exception handling
- Executive risk reporting

## Key Metrics

- Failed controls by severity
- High-risk cloud findings open
- Control remediation SLA performance
- Exceptions approved
- Repeat control failures

## Security Leadership Value

This project shows the ability to convert cloud security findings into governance decisions, owner accountability, and measurable posture improvement.
