# Detection Engineering Lab

## Source Repository

https://github.com/carrollj8471-ux/detection-engineering-lab

## Program Area

Detection Engineering

## Project Purpose

This project demonstrates how detection logic can be developed, tested, mapped to attacker behavior, and managed as part of a security engineering program.

## Technical Work Demonstrated

- Detection rule development
- MITRE ATT&CK mapping
- Test case design
- Alert validation
- Coverage gap analysis
- Sysmon and Wazuh telemetry validation
- ATT&CK-aligned case study documentation

## Management Integration

- Detection coverage management
- Monthly KPI reporting
- Risk register entries for critical gaps
- Quarterly review of detection priorities
- Security operations improvement planning

## Key Metrics

- ATT&CK techniques covered
- Detection tests passing
- Coverage gaps open
- High-priority detections validated
- False positive review outcomes
