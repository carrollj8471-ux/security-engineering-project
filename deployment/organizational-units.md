# Organizational Unit Design

## Purpose

The Organizational Unit (OU) structure organizes users, computers, groups, and administrators into logical containers.

## Design Goals

- Separate administrative functions
- Simplify Group Policy targeting
- Support least-privilege administration
- Improve scalability

## OU Structure

- Users
- IT
- Finance
- HR
- Workstations
- Servers
- Service Accounts
- Security Groups
- Admins

## Security Benefits

- Enables targeted Group Policy Objects (GPOs)
- Supports delegated administration
- Improves management of user and computer objects
- Aligns with common enterprise Active Directory practices
