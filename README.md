# Enterprise Security Engineering Management Lab

## Overview

This project demonstrates the design, deployment, hardening, monitoring, and detection of a Windows Active Directory enterprise environment using VMware Workstation, Windows Server 2022, Windows 11 Enterprise, Ubuntu Server, Wazuh SIEM, and Sysmon.

## Lab Components

- VMware Workstation
- Windows Server 2022
- Active Directory
- DNS
- Group Policy
- Windows 11 Enterprise
- Ubuntu Server
- Wazuh Manager
- Wazuh Dashboard
- Wazuh Agents
- Sysmon

## Objectives

- Identity Management
- Endpoint Security
- Security Monitoring
- Detection Engineering
- Security Governance
- Incident Response
- MITRE ATT&CK Mapping
