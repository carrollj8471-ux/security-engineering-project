# T1003.001 LSASS Memory Detection Lab

## Safety boundary

- Run only on the isolated WIN11 VM.
- Never dump, read, suspend, or alter the real `lsass.exe` process.
- Use only the renamed Notepad decoy under `C:\ProgramData\T1003-Portfolio-Lab`.
- Verify the decoy PID differs from the real LSASS PID before invoking MiniDump.

## Readiness

Confirm `Sysmon` and `WazuhSvc` are running and the Sysmon Operational log is enabled. Record a clean baseline for the lab path.

## Positive test

```powershell
$Lab = 'C:\ProgramData\T1003-Portfolio-Lab'
$DecoyPath = Join-Path $Lab 'lsass.exe'
$DumpPath = Join-Path $Lab 'benign-decoy.dmp'
New-Item -ItemType Directory $Lab -Force | Out-Null
Copy-Item C:\Windows\System32\notepad.exe $DecoyPath -Force
Remove-Item $DumpPath -Force -ErrorAction SilentlyContinue
$Real = (Get-Process lsass -ErrorAction Stop).Id
$Decoy = Start-Process $DecoyPath -PassThru
Start-Sleep 2
if ($Decoy.Id -eq $Real) { throw 'Safety assertion failed' }
& C:\Windows\System32\rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump $Decoy.Id $DumpPath full
Start-Sleep 5
[pscustomobject]@{RealLsassPid=$Real;DecoyPid=$Decoy.Id;SafetyCheckPass=$Decoy.Id-ne$Real;DumpCreated=Test-Path $DumpPath}
```

Expected: Sysmon Event `1` for Rundll32 and a dump only in the isolated lab directory.

## Wazuh validation

Deploy [detection-rules.xml](detection-rules.xml), run `/var/ossec/bin/wazuh-analysisd -t`, restart the manager only after a successful check, generate fresh activity, then query:

```text
agent.name:"WIN11" AND rule.id:"100223"
```

Expected: level `13`, T1003.001.

## Negative control

```powershell
$Control = Start-Process C:\Windows\System32\rundll32.exe -ArgumentList 'shell32.dll,Control_RunDLL' -PassThru
Start-Sleep 5
Stop-Process $Control.Id -Force -ErrorAction SilentlyContinue
```

Confirm the event is present under rule `100152` and absent from rule `100223` when filtered for `Control_RunDLL`.

## Cleanup

Stop only processes whose executable path equals the decoy path, remove the lab directory, restore the pre-test Sysmon configuration, and confirm Sysmon and Wazuh Agent remain running. Do not delete Windows or Wazuh event history.

## Troubleshooting

- Rules are not retroactive; generate a new event after deployment.
- If the event is in `archives.json` but not `alerts.json`, collection works and rule classification is the gap.
- Sysmon Event `10` can be absent because of configuration, provider, queue, or platform behavior. Do not disable LSA protection to force it.
- An empty dashboard result is meaningful only after confirming the control event reached manager archives.
