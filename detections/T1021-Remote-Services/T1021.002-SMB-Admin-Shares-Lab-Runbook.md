# T1021.002 SMB/Windows Admin Shares Detection Lab

> **Implementation note:** The validated rule is a child of custom rule `100208`, which processes PowerShell-launched `cmd.exe`. On this manager, child rule placement beside the parent branch was required for live evaluation.

## Portfolio objective

Validate an existing Windows remote-service path without enabling new services, confirm Sysmon and Wazuh visibility, create an ATT&CK-mapped administrative-share rule, test positive and negative behavior, export the alert, and verify cleanup.

## MITRE ATT&CK mapping

| Attribute | Value |
|---|---|
| Technique | `T1021.002 – SMB/Windows Admin Shares` |
| Tactic | Lateral Movement |
| Positive command | `cmd.exe /c "dir \\localhost\ADMIN$"` |
| Primary telemetry | Sysmon Event ID `1` |

## Lab environment

| Component | Value |
|---|---|
| Endpoint | `WIN11` |
| Wazuh agent | `WIN11`, agent `002` |
| User | `CORP\Administrator` |
| Wazuh manager | `wazuh-manager` |
| SMB endpoint | `localhost:445` |

## Safety boundaries

- Run only in the isolated lab.
- Use localhost unless a separately authorized second endpoint is available.
- Do not enable WinRM, RDP, SMB1, new shares, or firewall rules.
- Do not copy, create, modify, execute, or delete files through the share.
- List `ADMIN$` only.
- Verify no persistent network mapping remains.

## Detection hypothesis

Sysmon should record a PowerShell-launched command shell containing the administrative-share UNC path. Wazuh should collect that event. A child of the active `100208` branch should enrich it as T1021.002 while rejecting a local directory listing with the same process lineage.

## Phase 9: Install the final rule

Back up the file:

```bash
sudo cp /var/ossec/etc/rules/mitre_detection_rules.xml \
  /var/ossec/etc/rules/mitre_detection_rules.xml.bak-t1021-$(date +%Y%m%d-%H%M%S)

sudo nano /var/ossec/etc/rules/mitre_detection_rules.xml
```

Place this rule immediately after the `100208` branch and its existing child `100180`:

```xml
<rule id="100190" level="10">
  <if_sid>100208</if_sid>
  <field name="win.eventdata.commandLine"
         type="pcre2">(?i)ADMIN</field>
  <description>Windows administrative share accessed through a UNC path</description>
  <mitre>
    <id>T1021.002</id>
  </mitre>
  <group>lateral_movement,remote_services,smb_admin_share,</group>
</rule>
```

Validate and activate:

```bash
sudo /var/ossec/bin/wazuh-analysisd -t
sudo systemctl restart wazuh-manager
sudo systemctl is-active wazuh-manager

sudo grep -n -E 'id="(100208|100180|100190)"' \
  /var/ossec/etc/rules/mitre_detection_rules.xml
```

On WIN11:

```powershell
$LocalSmbConnections = Get-SmbConnection -ErrorAction SilentlyContinue |
Where-Object ServerName -eq "localhost"

[PSCustomObject]@{
    PersistentAdminMapping = [bool](
        net.exe use 2>$null | Select-String '\\localhost\ADMIN\$'
    )
    LocalhostSmbConnections = @($LocalSmbConnections).Count
    TestCmdProcesses        = @(
        Get-CimInstance Win32_Process -Filter "Name='cmd.exe'" |
        Where-Object CommandLine -Match 'localhost.*ADMIN'
    ).Count
    WinRMStatus = (Get-Service WinRM).Status
}
```

If and only if a persistent mapping exists:

```powershell
net.exe use "\\localhost\ADMIN$" /delete /y
```
